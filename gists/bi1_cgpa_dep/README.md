# CGPA vs Depression — Bivariate Grouped Bar Chart

## Description
This grouped bar chart explores the relationship between academic performance (CGPA range) and the presence of depression. For each CGPA range, two bars are shown side by side: one for students without depression (yellow) and one for students with depression (blue).

## Insight
Students in higher CGPA ranges (3.00–4.00) account for both the largest groups with and without depression, simply because that range concentrates most of the sample. Notably, maintaining a high GPA does not appear to protect against depression — a significant number of high-performing students still report depressive symptoms.
